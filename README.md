# RC Bluetooth Module Car

A Bluetooth-controlled robotic car built with an Arduino UNO and an HC-05 Bluetooth module, controlled wirelessly from a smartphone.

## Overview
- Wireless communication and control between a smartphone and the vehicle
- Forward, backward, left and right movements controlled remotely over Bluetooth
- Motor control circuitry driven by the Arduino UNO (ATmega328P)

## Components
- Arduino UNO (ATmega328P)
- HC-05 Bluetooth module
- Motor driver and DC motors
- Smartphone with a Bluetooth control app

## Tools Used
C++, Arduino IDE
